# DataFinder AI — MVP

محرك بحث عربي عن مجموعات البيانات في **Kaggle** و**Hugging Face**، يعرض بيانات وصفية وروابط حقيقية من فهارس المصدرين. لا يحمّل ملفات البيانات ولا يختلق نتائج.

## المميزات
- البحث بالعربي أو الإنجليزي مع قاموس توسيع كلمات عربي/إنجليزي بسيط.
- البحث بالتوازي في المصدرين، وفرز بالصلة/التحديث/التنزيلات.
- فلترة حسب المصدر والتاريخ والترخيص والصيغة **عندما تكون الصيغة معلومة من المصدر**.
- روابط مباشرة للمصادر وتصدير النتائج CSV.
- أخطاء API واضحة، وتخزين مؤقت للبحث لمدة 15 دقيقة.

> **مهم:** اسم AI يعبر عن الرؤية المستقبلية. النسخة الأولى ليست LLM Agent ولا تقدم تحققًا آليًا من جودة محتوى الملفات. المقارنة النصية مؤشر بسيط، ولا تمثل «نسبة صحة» أو ضمانًا للجودة.

## التشغيل المحلي
```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

## Kaggle authentication
قد يسمح Kaggle ببعض طلبات البحث العامة بدون مصادقة، لكن في كثير من البيئات يتطلب مصادقة. لإعدادها استخدم **واحدة** من الطريقتين:
- أنشئ API token من إعدادات حساب Kaggle واحفظه كـ `KAGGLE_API_TOKEN`.
- أو استخدم `KAGGLE_USERNAME` و`KAGGLE_KEY` من بيانات Kaggle القديمة.

القيم توضع في `.streamlit/secrets.toml` (انظر المثال المرفق) **ولا تُرفع إلى GitHub**. عند حدوث رفض من Kaggle، يظهر تنبيه مع استمرار البحث في Hugging Face. Hugging Face public search لا يحتاج عادةً إلى مفتاح. ويمكن وضع `HF_TOKEN` اختياريًا.

## النشر على Streamlit Community Cloud
1. أنشئ مستودع GitHub جديدًا، وارفع `app.py`, `search_sources.py`, `requirements.txt`, `.streamlit/config.toml` وباقي ملفات المشروع (عدا الأسرار).
2. افتح https://share.streamlit.io/ ثم **Create app**.
3. اختر المستودع والفرع وملف التشغيل `app.py`.
4. في **Advanced settings → Secrets** ضع مثلًا:
   ```toml
   KAGGLE_API_TOKEN = "YOUR_NEW_PRIVATE_TOKEN"
   # or legacy KAGGLE_USERNAME / KAGGLE_KEY
   ```
5. اضغط Deploy. يظهر رابط عام ينتهي بـ `streamlit.app`.

**لا تستخدم مفاتيح RapidAPI السابقة هنا.** المشروع يحتاج مفاتيح Kaggle إن لزم فقط. لا تنشر أي مفاتيح داخل الكود أو screenshots.

## قيود النسخة الأولى
- لا توجد ترجمة لغوية عامة؛ القاموس الحالي صغير ويمكن تطويره.
- فلاتر CSV/JSON تعتمد على وجود معلومات صيغ مؤكدة في نتائج المصدر، لذلك قد تستبعد نتائج مفيدة لا تعرض الصيغة.
- الحد الأقصى للعرض 70 نتيجة دون pagination. لا يوجد تنزيل مباشر لمجموعات البيانات.
- صحة الحقول وتوفر API يخضعان لتغييرات مزودي الخدمة، وأخطاء الاتصال ستظهر بوضوح.
- استعلامات المستخدمين المتكررة تستخدم cache مدة 15 دقيقة.

## الخطوة التالية
إضافة LLM اختياري لفهم العبارات العربية المعقدة، واستخلاص نطاق الدولة والفترة وهدف الاستخدام؛ مع إبقاء روابط وبيانات النتائج مستندة فقط إلى مصادر فعلية.
